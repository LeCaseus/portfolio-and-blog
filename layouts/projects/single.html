An undergraduate thesis project (2024–2025) that involved designing and developing an autonomous wrist splint to help individuals with Carpal Tunnel Syndrome manage muscle weakness and discomfort. Powered by an ESP32-WROOM microcontroller, the device uses EMG signals to monitor muscle activity and automatically adjust the splint's tightness, providing wrist support while allowing users to move their hands when needed.

The system features a biosignal-processing pipeline involving analog signal conditioning, notch filtering, digital signal reconstruction, and RMS-based threshold classification, which was evaluated by a licensed physical therapist. It also incorporates a built-in myofascial-release massage mechanism featuring two counter-rotating rollers driven by a central motor. The massage function operates on a scheduled 12-hour cycle, providing an additional rehabilitation and pain-relief feature.

A personal project (2026–present) focused on repurposing an HP EliteBook Folio 9480m into a home server that hosts my personal website and a collection of self-hosted services, including Navidrome, Miniflux, Umami, and other private applications.

The server runs on Linux, using Podman Quadlets managed through systemd to deploy and maintain containerized services. External traffic is routed through a Cloudflare Tunnel to Caddy, with Cloudflare Access securing private services and CrowdSec providing additional protection against suspicious activity. The setup also includes static network addressing and firewalld for network management.

To keep the services reliable and maintainable, I implemented automated nightly backups using restic, storing copies on an external drive and OneDrive. Additional maintenance tasks include scheduled database dumps and a custom notification and moderation tool for managing website interactions such as webmentions, guestbook entries, and comments.
